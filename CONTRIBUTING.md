# Adding to KOANS Wars

1. Fork or branch, change `index.html`, and run `python3 -m http.server 8000` to try it.
2. Open a pull request saying what you added and attach a screenshot.
3. Keep it one file with no build step, so anyone can open it.

## Good first things to add
- Rules: how a dynasty becomes the best (open question, see the issues).
- Make a skill do something on the field.
- Touch controls for phones.
- Your own dynasty, general, or units.

## Never put in this repo
It is public. No client names, no clinical, investor or financial information, no one's private messages, phone numbers or emails. Sample data only in `state.json`.
